# Copy（利用者が読む文字列）

- 常体で短く言い切る（「発火予定はまだない。」「〜に書く」）。です・ます調にしない — 既存の画面と README が常体のため
- 空状態は「何がないか」＋「どうすると出るか」の2文（例:「発火予定はまだない。下のフォームから予定を足すと、1分以内にここに出る。」）。空の理由を推測で書かない
- カレンダーは「起動用カレンダー」「記録用カレンダー」と呼ぶ。メイン・トリガー等の別名を使わない — AGENTS.md の3種の区別と一致させるため
- payload・notes・allowlist・tool・prompt など設定や Calendar API に出る語は英語のまま書く。訳すと利用者が Calendar 側で同じ語を探せない
- button 名は「動詞＋どこに」（「記録用カレンダーに書く」「承認して追加」）。「送信」「OK」にしない
- section の見出しの横の `<small>` には、その section の仕組み（誰がいつ何をするか）を1文で書く
- agent に信頼しないデータとして渡る入力（notes）は、入力欄の label にそう書く
